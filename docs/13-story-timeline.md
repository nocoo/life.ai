# 以时间为主干的每日实录

## 设计依据

本轮回看 `v0.2.1` 的 `dashboard/src/views/day/day-page.tsx`、`enhanced-timeline.tsx`、`activity-panel.tsx` 和时间聚合逻辑。旧版已经把时间置于中轴，活动与行迹、睡眠与身体指标分列两侧，用稳定的颜色及日夜变化帮助阅读；地图是一天的空间线索。1.1.0 把这些信息顺序堆在时间线前面，丢失了这种联系。

新页面把 24 小时重新放在阅读中心：左侧是身体指标与现场地图，右侧是运动、行迹、收支和生活片刻。时间主干贯穿全天，连接线把每条记录接回它发生的小时。四个时段只表示本地钟点分段，不推测日出日落。空白小时保持刻度，收窄留白；有记录的时段按内容展开。

- 健康与 GPS 高频样本归入所属小时、来源的分组，正文显示可读指标，原始记录按需展开。
- 身体指标用紧凑数值与真实心率样本曲线，运动在对侧呼应；消费收成带金额的小票，随记与行迹以文字为主，避免每一种数据都长成同一张卡片。
- 跨小时事件正文只出现在当天第一次覆盖的小时，后续小时用持续标记连接；来自前一天的事件明确说明。
- 每一组保留原始时间精度与时间范围。样本指标对应所显示记录的完整当日区间，不冒充逐小时测量。
- 全日地图接在最早的有效带时刻位置旁；每一段行迹可单独展开地图。只有日期的位置放在全天区，地图缺失不制造地点或默认路线。滚轮继续滚动页面，缩放按钮和键盘保留地图操作。
- 只有日期的记录安放在“全天”旁注，始终不编造钟点。
- 一日累计与手动 AI 总结作为时间主干的末页，读完故事后再回看。没有数据的指标不制造空卡片。
- 顶部保留紧凑的日期、来源筛选与 24 小时跳转条。移动端把左右枝条收为单列，保持时间顺序、可读宽度和键盘操作；地图紧随带位置的枝条，长标题可以换行。

Basalt 继续提供应用外壳、日期/筛选、按钮、披露、对话框和表层；时间主干、枝条与小型数据图形由项目 CSS/SVG 表达，不引入新的 UI 库。

## 协作与验证

仍在 `main`。Codex 负责每日投影、时间线、地图、样式和发布；grok 研究旧版、整理日末 AI 短笺并做只读设计复核；pi 复核投影与时间语义，补充 21 项 ViewModel 单测。协作按文件划定所有权，最后统一交回 Codex 集成与提交。

使用隔离的真实 Worker + SQLite 场景检查密集样本、跨小时事件、日期精度、地图关联、来源筛选、夏令时和移动布局。用有内容的一天进行桌面/移动、明暗主题截图复核，不能只以空页面或测试通过判断设计完成。生产验证不插入展示数据。

演示日 `2026-09-17` 含 121 条记录、五个来源，覆盖隔夜睡眠、晨跑、密集心率、早餐、两段轨迹、日历、书店随记、晚间运动和日记。L3 把这些记录写入隔离 SQLite；视觉预览拦截本地页面的全部 API GET，并拒绝非 GET 请求，AI 短笺也是预览文字。地图截图使用真实 OSM 瓦片，自动化交互测试使用固定瓦片。该场景没有进入生产数据。
