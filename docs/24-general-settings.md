# 24 通用设置与个人背景

侧栏底部的「设置」集中放置通用设置、AI 设置、Connect 和旧的日记导入。Footprint、Apple Health、貔貅入口仍在「数据管理」。设置导航与上方导航一起滚动，小屏幕也能到达所有入口；顶部 logo 的折叠锚点和底部 lizheng.blog 身份保持一致。

## 常用地点

在 `/settings/general` 点击「添加地点」，在地图上选中心点，用滑块或米数调整圆形范围，再保存名称。地图实时显示范围，支持移动中心、手动输入经纬度、编辑与删除多个地点。若从已加载的时间线进入，会用当天代表位置作为初始参考；没有轨迹时不假装已经选中地点。删除使用 Basalt 确认框。

使用既有 Leaflet 与 OSM 底图，没有新增地图依赖。地图实例保留到编辑器卸载，中心、半径和容器尺寸变化时更新范围；键盘逐字输入经纬度不会被格式化打断。表单保留非法数字供用户修正，不能用预览中的半径截断值替用户保存。底图失败可重试。

匹配以每个原始坐标为准，先查命名圆，再做原有 5/10 公里粗聚合：

- 同时命中多个圆时，半径更小的优先；再比较距离，最后以稳定 ID 决定。同一设置换顺序不改变命名结果。
- 距离很近的家和工作室仍是不同地点；未命中的邻近点不借用另一个点的名称。
- 家 → 家 → 工作室 → 工作室 → 家保留往返。每次到达的第一张地图展开，同一次停留中的后续地图折叠。
- 名称用于时间线位置卡、地图与弹窗、位置记录表、睡眠采样区域和日记。HTML 字符以文本展示，不作为 HTML 执行。
- 改名直接重投影已缓存的当天数据，原始坐标、样本数量、导入内容和时间戳不变。

名称表示用户现在赋予这个范围的含义，不能证明历史建筑用途、进入某栋楼或一整段时间都在这里。睡眠位置也只命名已有夜间采样支持的区域，不能单凭配置推断当晚在家睡觉。

## 惯常作息

可开启并填写平常入睡、起床时间及 IANA 时区，也可关闭并保存为 `null`。首次不预填普通人的睡觉钟点；时区初始取浏览器时区，用户可以修改。凌晨入睡、白天起床和跨午夜都有效，两个钟点不能相同。

作息是反复发生的当地钟表习惯，不能存成某天的 UTC 事件。健康观测仍存储和比较 UTC；给日记的证据同时将实际睡眠换成展示时区和作息时区，再比较早晚，自动遵循该日期的夏令时。例如八月纽约 21:00–05:00 对应上海次日 09:00–17:00，不能因为上海钟面显示白天就说用户作息颠倒。

实际睡眠优先。没有测到睡眠时，不能用设置补出这天几点睡、几点起或睡了多久；今晚入睡与归属本日起床的跨夜睡眠分别处理。模型可以据线索推测生活场景，不能把用户习惯当成观测或套用统一的早睡早起标准。

## 存储、接口与 MVVM

迁移 `0006_general_settings.sql` 增加 `general_settings`，只保存一行 `default`，包括全部地点与可选作息。不是每天或每个来源增加设置行。相同规范化内容的重复 PUT 不更新行或时间戳；读取空设置不创建行。

Access 保护的 `GET/PUT /api/settings/general` 返回 `{ data: { places, routine } }`。PUT 全量替换设置，最大 64 KiB；最多 100 个地点，名称最多 80 字，半径 50 米至 50 公里。机器导入域名不开放此 API。完整字段规则见 [10 Worker API](10-worker-api.md)。

分层：`models/general-settings` 负责共享校验和坐标匹配，`services/general-settings-service` 负责 HTTP，`viewmodels/general-settings-view-model` 负责读取、草稿和串行保存，View 使用 Basalt 渲染。共享设置 store 不随页面卸载清空；保存一块只合并另一块最后已保存的内容，同时保留另一块的未保存草稿。失败或过期响应不覆盖新状态。

## 日记与评测

日记材料区分个人背景和当天证据：列出可用名称与习惯，只有 GPS 实际命中的名称才出现在当天位置证据。命名位置不需要反向地理编码，也不受公共 GIS 最多四个区域的名额限制。日期级 GPS 保留日期精度。

设置参与日记输入哈希。查看日记和生成完成前都会核对当前设置；生成期间改名或修改作息会使返回结果标为过期，保留对应原材料的哈希。修改设置不自动付费重写，也不会丢失上一版成功保存的日记。用户可以带修改意见手动生成下一版。

原始 16 对写作评测和 4 对独立重复保持冻结。另增加六个虚构个人背景案例，覆盖晚睡习惯、仅改变习惯的反事实、睡眠缺失、命名地点与未到访地点、跨时区作息、实测优先。使用生产的坐标匹配和睡眠聚合，并检查实际模型正文。评分、校准限制与结果见 [23 日记评测](23-diary-eval.md)；软件测试通过率与模型写作评分分别报告。

## 验证范围

L1 覆盖设置校验、范围边界/重叠/日期线、匹配与睡眠故事、服务错误、并发保存与跨路由状态、日记证据和缓存失效。L2 使用真实隔离 Worker/D1，验证设置读写、幂等、鉴权/来源限制，以及真实模型 fixture 收到的个人背景与设置变更后的日记过期。L3 覆盖地图选择、半径预览、逐字坐标输入、保存与删除、作息、短屏导航，以及命名轨迹往返折叠、弹窗转义、改名后原始点不变。

自动测试只使用带标记的新本地数据库；Caddy 的生产数据开发与上线浏览器复核只读，不写入虚构地点、作息或日记。
