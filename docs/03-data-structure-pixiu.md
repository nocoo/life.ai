# 03 pixiu 记账数据结构

完整 2020–2026 导出的实测与按日存储建议见 [貔貅记账导入分析](19-pixiu-import-analysis.md)。本页保留原始九字段格式说明。

## 概览
这份数据来自 pixiu 记账软件导出，按年份拆分为 CSV 文件，每行代表一笔交易。

## 目录结构
```
/data
└── pixiu/
    ├── 2022.csv
    ├── 2023.csv
    ├── 2024.csv
    └── 2025.csv
```

## CSV 字段
字段采用逗号分隔，首行为表头。

- `日期`：来源记账日期（YYYY-MM-DD），用户已确认是北京时间 UTC+8；导出未提供时分，不推断交易时刻
- `交易分类`：一级分类（例如：日常支出、日常收入）
- `交易类型`：二级分类（例如：超市、工资）
- `流入金额`：该账户流入金额（原始两位小数字符串，并非都属收入）
- `流出金额`：该账户流出金额（原始两位小数字符串，并非都属消费）
- `币种`：币种（例如：人民币）
- `资金账户`：资金账户名称
- `标签`：可选标签（例如：周期费用、工资）
- `备注`：可选备注

## 规则说明
- 同一行至多有 `流入金额` 或 `流出金额` 之一非零；双零流水也需完整保留
- `交易分类` 除日常收入/支出外，还包括转账、还款、余额调整、赎回等；分类与金额方向必须同时保留
- `交易类型` 为二级分类，可用于统计与聚合
