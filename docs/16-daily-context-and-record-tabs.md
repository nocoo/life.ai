# 16 每日环境、小时地图与原始记录页签

日期：2026-09-14。版本：1.4.0。沿用 [15 数据管理](15-data-management.md) 的 Footprint 日包和导入契约，本次不修改数据库结构，不重复导入生产 GPS。

## 每天的阅读方式

Basalt `PageHeader` 统一每日实录、数据概览、Footprint、其他导入、Connect 和 AI 设置的标题、副标题与内容对齐。每日页面铺满内容区，保留两侧枝条和宽屏多列，右侧独立 metadata 列集中展示全天足迹、天气、一日累计、只有日期的记录及手动 AI 总结。全天内容不再占用零点刻度。

页面使用 Basalt Tabs：

| 页签 | 内容 | 挂载与数据 |
| --- | --- | --- |
| 时间线 | 24 个本地小时、关键事件、小时地图和天文时刻 | 首次默认页；只挂载地图与汇总，不构造原始记录列表 |
| 位置记录 | GPS 和原始轨迹表格，时间、精度、来源、经纬度、海拔、原始速度和航向 | 首次点击才加载表格模块，每页 50 行 |
| 其他记录 | 健康、运动、记账、随记和推送记录的表格 | 按需挂载，每页 50 行，支持完整记录详情 |

日期和来源筛选对三个页签一致。切换页签复用已读取的当天数据，不重新读取 D1；切换来源也使用当天缓存。换日或来源变化后表格回到第一页，页签选择保留。地图筛选仅在时间线显示。离开时间线会销毁 Leaflet 实例和观察器；返回后按当前地图模式重新初始化可见地图。

表格使用 Basalt `DataTable` 的列排序、分页、横向滚动与空状态。ViewModel 按事件 ID 去除跨小时的同一记录，不按时间戳去重，因此同一秒不同 GPS 点仍全部保留。按 UTC 瞬间排序，展示时转换为设备当前时区；日期精度显示“全天”。坐标、负海拔、`speed=-1`、`course=-1`、零和缺失值都保持原意。旧的整段轨迹数组作为一条原始记录保留，不再次展开成大量行。

点击单条详情才序列化其完整 JSON 并挂载一个 Basalt Dialog，关闭后焦点返回原按钮。原始 UTC、嵌套字段和完整轨迹数组可在这里核查。时间线中原有的 GPS 大列表和健康分组原始卡片列表已移除，单条叙事事件仍可展开轻量详情。

## GPS 区域、停留与小时地图

区域默认半径 5 km，可切换到 10 km。每个区域以首次观测点为固定中心，避免不断移动中心导致区域链式漂移；保留 A → B → A 的访问顺序。半径切换只重算本地投影。

每小时合并这一小时的区域和样本，最多一张行迹地图；地图旁按时间列出这一小时经过的区域。连续停留时，第一张地图展开，后续同一区域的地图收起并显示点数和距离。离开后返回同一区域会重新展开；不能因该区域在当天出现过就把新的到达折掉。跨多个区域的路段保持展开。无采样的小时不制造停留记录，也不把长采样空档算成连续停留时间。

“展开地图 · 合并重复”是默认模式；可选择展开全部或收起全部。换到新的一天恢复默认。收起的地图不创建 Leaflet；展开的地图在距视口 400px 内才加载。原生轨迹断点、超过 30 分钟的空档、同刻点和跨 180° 经线之间不虚构连线。全天地图仍展示完整日内轨迹，ResizeObserver 在窗口或侧栏宽度变化后重新容纳完整路线。

位置编号使用圆形标记，数字中心与圆心一致，不受 Leaflet 延迟加载的样式覆盖。速度颜色使用相邻有效采样点的球面距离除以 UTC 时间差估算：

| 档位 | 估算速度 | 展示 |
| --- | --- | --- |
| 慢速 | 小于 6 km/h | 绿色 |
| 中速 | 大于等于 6、小于 30 km/h | 黄色 |
| 快速 | 大于等于 30 km/h | 粉色 |
| 未知 | 孤立点、无有效邻边或只有日/小时精度 | 中性虚线边框 |

采样点也使用对应颜色和大小。起终点用中性方标区分，弹窗说明估算速度。Footprint 原始 speed 的单位未知，因此不把它当作 km/h 或 m/s；表格保留原值。颜色不推断步行、开车等交通方式。

## 天气与天文时刻

参考位置优先选择当天连续采样时间最多的区域，再按点数和出现顺序确定。多来源重叠采样时间取并集，空档不累计。外部查询坐标按两位小数处理，界面标明参考区域。没有 GPS 时不默认城市。

- Open-Meteo 的历史/预报接口返回 UTC Unix 小时数据；按选中本地日对应的 UTC 窗口裁剪，汇总温度、降水、风速和天气。降水时刻 `t` 表示 `(t−1h, t]`，避免把本地日边界外的雨量加进来。超出支持范围显示不可用。
- Sunrise-Sunset v2 查询相邻日期，读取 UTC Unix 日出日落，再按本地日筛选、排序并放到正确的小时。支持极昼/极夜，不制造不存在的时刻。
- 浏览器直接调用公开 API，不携带本站凭据或 Referer；每次读取限 128 KiB、12 秒超时，换日取消请求并忽略旧响应。天气与天文分别显示加载、失败和重试状态。

公共 API 和地图瓦片不写入 D1。当天数据由生产日包读取，展示天气或切换页签不会增加 GPS 数据行。

## 数据管理与 Basalt 整理

数据概览使用 Recharts 3.10.1，复用 Basalt 的 `ChartFrame`、图表配色、坐标轴/网格配置、Tooltip 和 Legend。按月记录量补齐首尾之间的缺失月份，窄屏可以横向滚动；来源对照可切换覆盖日、原始记录、数据行和 JSON 正文大小，不重复请求。全局覆盖日取各 provider 的 UTC 日期并集。

总览、来源统计和覆盖日历统一使用 `LayerCard`、`StatStrip`、`Table` 与 `SectionRule`。刷新失败保留上次成功数据。JSON 正文大小不冒充 D1 物理占用。

Footprint 独立页面使用 `PageHeader`、`FileDropzone`、`UploadQueue`、`StatStrip` 和预览 `Table`；宽屏右侧放导入目标与覆盖规则。累计统计仍只放数据概览。本次数据目标确认和过期请求处理修复沿用共享导入模块，不改变整日覆盖、幂等或机器导入方式。
