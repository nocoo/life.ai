2026-09-14。与 [按天数据源、出行与通勤](25-day-sources-and-travel.md) 一起纳入 2.0.0。此次只修改 Life.ai；Surety、Basalt、Firefly 和 Gecko 仓库仅供只读核验。

## 睡眠阶段

每日时间线的睡眠卡按苹果健康的参考图呈现：先显示实际睡眠时长与醒来日期，再显示清醒、快速动眼、核心、深度四层阶段图。时间轴跨午夜连续；色块宽度取自原始阶段的起止时间。入睡、起床、在床及清醒总时长保留在图下。

- 清醒使用珊瑚色，快速动眼使用青色，核心使用蓝色，深度使用靛色；均使用 Basalt 的明暗主题 token。
- 点击、悬停或键盘聚焦色块可查看阶段、起止日期时间和持续时长，秒级短片段不会变成 0 分钟。
- 只连接时间恰好相邻且阶段不同的色块；缺测空隙和重叠观测不画成连续转变。在床记录不当成睡眠分期。
- 未分期记录独立显示为“睡眠（未分期）”；只有未分期数据时，不显示不存在的核心、深度或 REM 分期。
- 坐标计算在 `src/viewmodels/sleep-stage-chart.ts`，薄组件 `src/components/sleep-stage-chart.tsx` 使用原生 SVG 与按钮，不增加绘图库依赖。
- 沿用原有睡眠来源选择、重叠去重和醒来日归属。无时区偏移的输入按 UTC 解析。此次可视化不改原始健康记录、睡眠统计或日记证据。

## 侧栏与头像

参考 Surety 的布局处理，Basalt `Sidebar` 外层保留宽度动画，内部区域切换到固定布局并由外层裁剪，避免导航图标和搜索文字被中间宽度挤压。使用同一个 header、logo、切换按钮与头像节点。

桌面 logo 的可见锚点为左 24 px、上 16 px，尺寸 24 × 24 px；展开、收起及快速反向切换均不移动或重新挂载。头像固定左 16 px。导航及底部设置在短屏中一起滚动，logo 与用户区域留在原位。减少动态效果偏好会关闭宽度动画；手机继续使用展开的导航抽屉。

左下角沿用真实 lizheng.blog 公共作者服务：Worker 将当前认证邮箱 trim/lowercase 后取 SHA-256，调用 `GET https://lizheng.blog/api/authors/profile?hash=...`，读取裸 `{ name, avatar }`。API 超时、无公开作者或图片加载失败时回退到会话身份与首字母。保持 2.5 秒超时、16 KiB 上限、HTTPS 图片和禁止重定向约束；不改变 Access 认证。开发环境使用固定开发身份，因此没有对应公开作者时显示回退头像，不冒充生产用户。

## 页面骨架屏

统一复用 Basalt `SkeletonLine`，占位使用 `role=status`、明确的加载名称与 `aria-busy`，不提供可交互的假控件。各页面按实际区域保留布局：

| 页面或区域 | 加载布局 |
| --- | --- |
| 时间线 | 时段导航、双侧时间轴卡片、当天概况、天气与日记；窄屏跟随真实时间轴排列 |
| 位置 / 账目 / 其他记录 | 相应列数的表头与行、横向滚动容器、分页区域 |
| 数据概览 | 四项统计、280 px 月度图、来源图表与对照表 |
| 通用设置 | 常用地点列表及惯常作息表单；未读取设置前不闪现“没有地点”或默认可编辑表单 |
| AI 设置 | 模型卡内部保留提供方、模型及按钮的空间 |
| 数据源 | Gecko、Firefly 与 GitHub 三张卡，分别匹配密钥输入、公开连接和 PAT |
| Connect | 签发区域与已签发令牌列表各自加载 |
| Footprint / Apple Health / 貔貅 | 各自的上传区域、说明与写入位置；只等环境信息时保留已经可用的上传界面 |
| 日记导入 | 来源与文件、进度两块区域 |
| 日记 / 天气 / 日出日落 | 真实卡片内部的内容占位；换日期时不展示旧日记 |
| 运动路线 / 心电图 | 地图空间、148 px 波形和翻页区域；错误时切换到明确的提示和重试 |

路由模块懒加载也使用对应页面布局。已有数据刷新时保留当前内容，不重新覆盖整页占位。
